# Security Policy

## Supported Versions

We actively maintain and provide security updates for the latest release on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please do **NOT** open a public GitHub issue.

Instead, please report it privately by sending an email to:
📧 **bonheurndezenc@gmail.com**

### Please include in your report:
- A description of the vulnerability
- Steps or proof of concept to reproduce the issue
- Potential impact of the vulnerability
- Any suggested remediations

### What to expect:
- You will receive an acknowledgment of your report within 48 hours.
- We will work promptly to investigate and patch the issue.
- Once fixed, a security advisory will be published and credit will be given to the reporter (if desired).

Thank you for helping keep this project secure!
